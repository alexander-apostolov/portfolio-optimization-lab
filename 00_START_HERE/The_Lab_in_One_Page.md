# The Lab in One Page

Portfolio Waste Discovery Lab is a reproducible method-comparison environment for identifying economic waste in portfolio allocation and reallocation. It uses a controlled context with budget profiles, constraint-capacity profiles, structural dependencies, synergies, asymmetric uncertainty, stochastic feasibility, and cost-of-time logic.

The current validated baseline is V18, internally traceable to POL Iteration 3 / R7, but the package is not named after R7. R7 is a traceability label, not the identity of the tool.

The central question is: how much economic value is left unrealized by each method, in each world, and why? The package reports P85, feasibility, selected projects, sequences, project and portfolio periods, WIP, budget/constraint utilization, ROI, reserve-adjusted ROI, waste, and suspicious-signal checks.
