# Method Comparison Guide

The lab compares portfolio allocation and reallocation methods in the same controlled environment. The comparison unit is a world-method portfolio configuration: selected projects, sequence, staged master portfolio schedule, and stochastic P85 evaluation.

DBR is the current macro-scheduling context: project work packages pass through a constrained portfolio drum and budget/constraint capacity are tracked by period. DBR is not the method. The lab is a comparison and waste-discovery framework.

Fair comparison requires same worlds, common MC scenarios, same structural/budget/constraint/synergy/cost-of-time rules, and method-specific intelligence only within each method's definition.
