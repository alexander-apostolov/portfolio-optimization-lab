# Master Portfolio Schedule Context

The benchmark uses a master portfolio schedule, not a detailed project schedule. Each project is treated as a work package with duration, budget usage, constraint usage, dependencies, synergies, and cost-of-time behavior.

Drum-Buffer-Rope concepts represent the current portfolio constraint and release/staging context. Detailed task networks, crews, calendars, materials, and activity critical paths are outside this package's scope and can be handled downstream in a detailed scheduler.
