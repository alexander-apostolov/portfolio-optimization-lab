# Definitions of Done and Ready

Done means the package contains human explanation, engine/reproduction layer, current baseline, continuation workspace, audit tools, full baseline rerun wrapper, continuation smoke test, manifest, and attribution.

Ready for handoff means content audit, raw-to-summary recomputation, method invariants, period feasibility, waste recomputation, suspicious-signal audit, full baseline reproduction capability, continuation smoke test, and known-limitations documentation have all passed or are explicitly documented.
